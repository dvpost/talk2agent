# Готовность к внедрению и статусы соответствия

## Для внедрения стандарта во всём сервисе

- [ ] Есть воспроизводимые способы запуска и проверки сервиса.
- [ ] Агентная точка входа коротка, требует применять workflow, указывает на локальный индекс пакета и действующую архитектуру. Канонические навыки и Claude-адаптеры доступны из нативных каталогов; локальные ссылки проверены. Версия и источник указаны только в README пакета.
- [ ] Ключевые компоненты, границы и сквозные потоки документированы с подтверждениями.
- [ ] Проведён содержательный аудит модульности: установлены фактические зоны ответственности, выявлены смешанные модули, god objects, запрещённые зависимости/циклы, дублирование и избыточная фрагментация; проблемные места подтверждены путями/символами, исправлены безопасно либо учтены **только в `TODO/`**, без самовольного массового рефакторинга.
- [ ] Проведён аудит мёртвого кода (включая отключённые ветки, неиспользуемые реализации, feature flags, адаптеры, конфигурацию и закомментированные блоки): подтверждённо ненужное безопасно удалено в рамках полномочий; неизвестные внешние/динамические потребители исследованы; заблокированные удаления учтены **только в `TODO/`** и не маскируются заявлением о полном соответствии.
- [ ] Там, где структура оправдывает контроль, границы между ключевыми слоями/модулями проверяются релевантными автоматическими средствами или явно обозначен проверочный пробел.
- [ ] Качество тестов проверено согласно [«Тестирование»](../../convention-testing/references/test-design.md): выявлены пробелы сценариев, пустые/зависимые от реализации assertions, скрытые данные, неверный уровень, избыточные моки и нестабильность. Значимые проверки доступны либо ограничения известны; незакрытые проблемы зафиксированы в `TODO/`, без массового переписывания тестов ради стиля.
- [ ] Постоянная документация отражает **CURRENT STATE ONLY**, без будущих функций, roadmap, TODO-списков или незавершённых требований.
- [ ] Подробные документы размещены в `docs/`; в корне только разрешённые [«Размещение документов»](../../convention-documentation/references/repository-contract.md) документы. Все ссылки и зависимые инструменты соответствуют размещению, прежние копии и корневые заглушки убраны.
- [ ] Выполнена проверка полезности и дублей согласно [«Полезность и единый источник»](../../convention-documentation/references/writing.md#полезность-текста-единый-источник-и-границы-отчётов): общий стандарт не пересказывается в справочниках проекта; README и другие постоянные документы не хранят самопохвалу, статус соответствия всего сервиса и результаты разовых проверок. Короткое объявление применяемой конвенции ведёт к локальному индексу пакета.
- [ ] **ALL PLANS IN `TODO/`**: выявлены и перенесены все планы из `docs/`, README, AGENTS, ADR, заметок и комментариев; дубликаты удалены. Устаревшие и заменённые ADR и схемы исключены из активного контекста.
- [ ] Действующие миграции и режимы совместимости корректно выделены, не удалены по ошибке.
- [ ] Все обнаруженные retry/fallback, скрывающие ошибки и гипотетические защитные обёртки оценены и двусторонне сверены с `docs/exceptional_execution_paths.md` по ID, местоположению, текущим лимитам, согласованию и тестам. Сам реестр присутствует даже без исключений. Несогласованные/сомнительные случаи отражены в `TODO/`, без самовольного опасного удаления.
- [ ] Документация не описывает гипотетические запасные сценарии как действующие; одобренные механизмы описаны точно, кратко и только в текущем состоянии.
- [ ] Открытый реестр несоответствий и будущие корректирующие действия находятся **в `TODO/`**; не предпринято опасных изменений без разрешения.
- [ ] Отчёт ясно разделяет проверенное, предполагаемое и неизвестное.

## Статусы соответствия

| Статус | Значение |
| --- | --- |
| `COMPLIANT` | Применимые обязательные требования выполнены и проверены |
| `PARTIALLY COMPLIANT` | Некоторые требования выполнены; оставшиеся пробелы указаны |
| `NON-COMPLIANT` | Известны существенные несоблюдённые обязательные требования |
| `NOT ASSESSED` | Недостаточно исследования или подтверждений для оценки |

Наличие файлов с подходящими именами **не равно соответствию**. Статус всего сервиса — обязательная часть только полноценного аудита, а не каждого мелкого коммита. Он относится к итоговому отчёту конкретного аудита и не публикуется как постоянная декларация в README, агентных инструкциях или справочниках ([«Полезность и единый источник»](../../convention-documentation/references/writing.md#полезность-текста-единый-источник-и-границы-отчётов)). Обязательный статус проверки реестра исключительных путей согласно [«Реестр исключительных путей»](../../convention-coding/references/exceptional-execution-paths.md) сохраняется отдельно.
